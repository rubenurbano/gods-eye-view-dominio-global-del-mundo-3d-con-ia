Capítulo 1

Introducción: La Perspectiva de Dios en la Era de la Información

En la arquitectura de la información contemporánea, la fragmentación de datos es el mayor obstáculo para la toma de decisiones estratégicas. God's Eye View (GEV) emerge no solo como un visualizador, sino como un ecosistema de Geospatial Data Fusion diseñado para centralizar telemetría masiva en un centro de operaciones unificado.

Desarrollado por Bilawal Sidhu, ex-Product Lead de Google Maps, GEV traslada la potencia de las herramientas GEOINT (Geospatial Intelligence) de nivel gubernamental al entorno local y privado del analista.

Como estratega, entienda GEV como un cliente 3D de código abierto cuya misión es la síntesis: unir hilos de datos dispersos para generar poder situacional. En un mundo donde la IA y los datos en tiempo real convergen, dominar esta herramienta permite monitorizar infraestructuras críticas, rastrear activos globales y realizar análisis ambientales con una profundidad fotorrealista.

Transformación El impacto es transformador: el usuario deja de ser un consumidor pasivo de noticias fragmentadas para convertirse en un observador activo y analítico de la realidad física global.

Análisis de la Naturaleza de los Datos

Para un análisis profesional, es vital distinguir entre observación directa y reconstrucción algorítmica. GEV emplea técnicas de Data Interpolation (o dead reckoning) para suavizar la representación de objetos entre cada "ping" de señal (que suele ocurrir cada 15-30 segundos), evitando saltos visuales bruscos y proporcionando una trayectoria fluida pero estimada.

Tipo de InformaciónEjemplosMetodología de Interpretación
Telemetría / Feed Vuelos (ADS-B), barcos (AIS), sismos. Observación de fuente externa con refresco constante. Sujeta a latencia.
Agregado Tráfico TomTom. Velocidad y flujo real; los vehículos individuales son representaciones simuladas basadas en la densidad.
Estimado Cobertura CCTV, trayectorias de lanzamiento. La posición de la infraestructura es real; la orientación (pose) y el viewshed son reconstrucciones.
Estático Cables submarinos, presas, datacenters. Datasets fijos de alta precisión que requieren actualizaciones periódicas del repositorio.
Analogía Técnica GEV actúa como un radar de aproximación de alta fidelidad que, simultáneamente, proyecta capas de inteligencia comercial. Mientras que un mapa estándar solo muestra "dónde" hay tráfico, GEV utiliza el flujo de datos para reconstruir una simulación dinámica del entorno.
⚠ Aviso Profesional Esta no es una herramienta de navegación operacional. El sistema puede presentar datos tardíos o incompletos. No debe utilizarse para la gestión de emergencias críticas o decisiones de seguridad física.

Capítulo 3

Guía de Instalación Paso a Paso: Elige tu Camino

La estabilidad operativa de GEV depende de la integridad del entorno local. Seleccione el método según su perfil de gestión de sistemas.

Método A: Pinokio (Instalación Abstraída)

Ideal para despliegues rápidos donde se prefiere delegar la gestión de dependencias.

  1. Requisito: Descargue Pinokio (versión 8.2 o superior).
  2. Localización: En la pestaña "Explorar", busque God's Eye View.
  3. Despliegue: Ejecute Install y luego Start. El motor elegirá automáticamente un puerto libre en su máquina.

Método B: Terminal (Control de Arquitectura)

Recomendado para analistas que requieren un control granular del entorno.

Requisito de Node.js Es mandatorio utilizar la versión 24.14.0+ o la rama 26.x. La versión 25 está en estado End-of-Life (EOL) y provocará fallos en el diagnóstico. 
git clone https://github.com/bilawalsidhu/gods-eye-view.git
cd gods-eye-view
npm ci
npm run doctor  # Procedimiento de verificación de salud del sistema
npm run dev     # Lanzamiento del servidor en http://localhost:4173

Checklist de Primer Arranque

Al iniciar, el sistema ofrece cuatro paradigmas de visualización:

  • Live Contacts: Optimizado para aviación y seguimiento de activos.
  • Space Missions: Enfoque en telemetría de lanzamientos y órbitas.
  • Environmental: Prioriza capas de incendios (FIRMS) y sismos (USGS).
  • Explore Manually: Modo libre para configuraciones personalizadas.

Una vez desplegado, el dominio de la interfaz transforma la navegación en una operación de inteligencia.

Capítulo 4

Dominio de la Interfaz y Control de Mandos

La jerarquía visual de GEV está diseñada para minimizar la fricción cognitiva. La maestría se alcanza mediante el uso de atajos que permiten una navegación fluida sin desviar la atención de los datos.

La Ruta Crítica de 5 Minutos

  1. Fusión de Vuelos: Active la capa Flights. Seleccione una aeronave para bloquear la cámara e iniciar el seguimiento de telemetría.
  2. Inmersión en COCKPIT: Pulse la tecla C. La cámara se anclará a la posición del activo, permitiendo observar el terreno desde su perspectiva.
  3. Análisis de Infraestructura: Con el 3D activo, descienda a nivel de suelo en un aeropuerto para visualizar grounded contacts.
  4. Verificación CCTV: Active las cámaras y utilice la función VIEWSHED para proyectar el cono de visión estimado sobre el terreno 3D.

Capítulo 5

El Panel de Power Ups: Potenciando el Globo con APIs

Los "Power Ups" son conectores de API Proxying que elevan el sistema de una base de datos pública a una herramienta de fotorrealismo extremo. GEV es keyless de serie, pero las APIs actúan como multiplicadores de capacidad.

Fichas Técnicas de Proveedores

1 Google Maps Browser-side

Desbloquea Photorealistic 3D Tiles.

Necesidad: Crítica para realismo.
Acción: Requiere activar el "Map Tiles API" en Google Cloud y vincular billing.
Cuota: $200 de crédito mensual (aprox. 1,000 root tokens/mes).

2 Cesium ion Browser-side

Alternativa 3D.

Configuración: Cree un token en ion.cesium.com con el scope restringido exclusivamente a assets:read.
Cuota: 1,000 root tiles/mes en plan Community.

3 OpenAI Server-side

Activa el Agente de Voz y control por lenguaje natural.

Coste: Pago por uso (Modelo Realtime).
Seguridad: GEV gestiona la clave en servidor y entrega un token temporal al cliente.

4 AISStream Server-side

Seguimiento de buques.

Acción: Genere la clave en aisstream.io mediante GitHub OAuth.
Límites: Máximo 3 conexiones abiertas por cuenta.

5 NASA FIRMS Server-side

Detección de incendios.

Clave: Obtenga la MAP_KEY gratuita mediante registro por email.
Cuota: 5,000 transacciones cada 10 min.

6 TomTom Server-side

Tráfico real agregado.

Acción: Registro en el portal developer.
Free Tier: 20k-200k peticiones según el endpoint.

7 OpenSky Server-side

Mejora el polling de vuelos de 10s a 5s.

El modo anónimo funciona por defecto; el registro amplía la cuota diaria.

8 Launch Library 2

Datos de misiones espaciales.

Gratuito sin clave para 15 consultas/hora.

Estrategia de Seguridad de Claves

  • Browser-side (Google/Cesium): Estas claves se exponen en el código del navegador. Es obligatorio restringirlas mediante "HTTP Referrer" a su dominio local o IP de servidor para evitar el robo de cuota.
  • Configuración de Emergencia: Si tras insertar claves el panel de Power Ups desaparece, añada el parámetro ?setup=1 a la URL para forzar la visualización del gestor de credenciales.
Capítulo 6

Operaciones Avanzadas: Casos Prácticos de Uso Global

Caso 1: Inteligencia Aeronáutica

Al realizar el tracking de un vuelo, GEV aplica interpolación de señales para suavizar el movimiento. El analista puede alternar a óptica FLIR (tecla 3) para realizar una inspección visual simulada de las emisiones térmicas del fuselaje en 3D.

Caso 2: Monitorización de Activos Marítimos

Utilice AISStream para identificar buques en zonas de congestión (ej. Canal de Suez). Al seleccionar un buque, use la función de cámara más cercana para verificar visualmente el entorno mediante CCTVs públicas, cerrando el círculo entre telemetría y observación visual.

Caso 3: Vigilancia Ambiental OSINT

La capa NASA FIRMS muestra anomalías térmicas en una ventana móvil de 24 horas.

Interpretación Un hotspot indica una detección satelital, no un streaming. El arquitecto de información debe cruzar este dato con la capa de sismos (USGS) para evaluar si existe un evento geológico subyacente.
Capítulo 7

IA y Agente de Voz: Hablando con el Planeta

La integración de OpenAI actúa como una capa de Visual Grounding. El sistema puede interpretar lo que ocurre en el viewport para responder preguntas complejas.

Comandos de Navegación

"Take me to the Port of Rotterdam and orbit the largest container ship."

Interrogación de Capas

"How many flights are currently over the Mediterranean?"

Gestión de Gasto GEV implementa un monitor de sesión con avisos a los $2 y un corte duro a los $5 para evitar sorpresas en la facturación de OpenAI.
Nota Ética El sistema excluye deliberadamente algoritmos de reconocimiento facial o seguimiento de personas físicas, enfocándose exclusivamente en activos y eventos globales.
Capítulo 8

Seguridad y Despliegue en VPS

GEV es un sistema local-first, diseñado para proteger su privacidad de datos. No obstante, su despliegue en servidores remotos (como Hostinger o Linux) requiere medidas adicionales:

  1. Gestión de Secretos: Las claves se almacenan en .env (Terminal) o pinokio/ENVIRONMENT. Nunca incluya estos archivos en repositorios públicos.
  2. Proxy Inverso: Es imperativo utilizar Nginx o Caddy con una capa de autenticación fuerte (Basic Auth o similar).
  3. Aislamiento: En instancias compartidas, el panel Provider Settings se desactiva para evitar el "broker de claves", donde otros usuarios podrían extraer sus credenciales configuradas.
Capítulo 9

Resolución de Problemas (Diagnóstico)

Regla de Oro Ante cualquier anomalía, la regla de oro es el Retorno al Estado Keyless. Si el sistema funciona sin claves, el error reside en la última configuración API añadida.
SíntomaCausa ProbableAcción de Remediación
Globo funcional pero sin 3D. Error de facturación o restricción. Verifique el saldo en Google Cloud o el token de Cesium.
Fallo de conexión AISStream. Exceso de sesiones activas. Regenere la clave; asegúrese de cerrar sesiones previas (máx. 3).
Error de Node al arrancar. Versión incompatible. Use nvm para cambiar a Node 24.14+ o 26.x.
Panel Power Up oculto. Layout o estado del servidor. Añada ?setup=1 al final de la URL del navegador.
Capítulo 10

Conclusión, Recursos y Glosario

Retos Prácticos (Soluciones paso a paso)

Reto OSINT: Verificación de Incendio

  1. Active el modo Environmental y encienda la capa NASA FIRMS.
  2. Localice un hotspot activo (punto rojo) y haga clic para centrar la cámara.
  3. En el panel de información, pulse el botón "Nearest CCTV".
  4. Si hay una cámara disponible, verifique la columna de humo para confirmar la magnitud del incendio.

Reto Aeronáutico: Aproximación Final

  1. Busque una aeronave alineada con la pista de un aeropuerto internacional (ej. Barajas o LAX).
  2. Haga clic en el avión y pulse C para entrar en el Cockpit.
  3. Pulse 2 para activar la Visión Nocturna (NVG) y observe cómo el relieve 3D se destaca mediante el motor visual.
